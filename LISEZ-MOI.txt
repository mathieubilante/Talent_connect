\xef\xbb\xbfTALENTCONNECT - DEMARRAGE RAPIDE (Windows)
==========================================

CE QU'IL FAUT AVOIR (une seule fois)
- Python 3.10 a 3.12   https://www.python.org/downloads/   (cocher "Add Python to PATH")
- Node.js (version LTS)  https://nodejs.org
Pas besoin de Docker ni de PostgreSQL : le projet utilise SQLite par defaut.

POUR LANCER LE SITE
1. Placez ce dossier dans un endroit simple, par exemple H:\TalentConnect
   (ne le deplacez plus apres l'installation).
2. Double-cliquez sur   1_INSTALLER.bat     (une seule fois, quelques minutes)
3. Double-cliquez sur   2_LANCER.bat        (a chaque fois que vous voulez utiliser le site)
   Deux fenetres noires s'ouvrent : ne les fermez pas. Le navigateur s'ouvre sur le site.

TESTER L'INSCRIPTION AVEC CODE OTP
1. Sur le site : "S'inscrire" -> remplir le formulaire -> "Recevoir mon code".
2. Le code a 6 chiffres s'affiche dans le cadre orange et dans la fenetre noire "API".
3. Saisissez le code -> vous entrez sur le site.

TESTER LES DOCUMENTS D'IDENTITE (KYC)
1. Connectez-vous en candidat (kofi@demo.tg) -> menu "Documents" -> choisissez un PDF, JPG ou PNG pour la CIN.
2. Connectez-vous en entreprise (tech@demo.tg) : 3 documents (CIN du representant, patente, extrait RNE avec sa date d'emission).
3. Connectez-vous en administrateur : section "Dossiers de documents (KYC)" -> telechargez un document.
Les fichiers sont stockes CHIFFRES dans backend\uploads\kyc (illisibles sans la cle).

TESTER LA VALIDATION PAR L'ADMINISTRATEUR
1. Deposez des documents en candidat (kofi@demo.tg) ou en entreprise (tech@demo.tg).
2. Connectez-vous en administrateur -> section "Examen des dossiers (KYC)".
3. Refusez un document (motif obligatoire), puis validez les autres. "Valider le compte" n'est possible que si TOUS les documents sont valides.
4. Reconnectez-vous en candidat/entreprise : "Mon compte" montre les etapes et les notifications donnent les motifs.

TESTER LE SITE D'EMPLOI PUBLIC (sans connexion)
1. Ouvrez http://localhost:5173 SANS vous connecter : recherche, secteurs, offres recentes, entreprises.
2. Cliquez sur une offre : detail + offres similaires. "Postuler" vous envoie vers la connexion puis revient sur l'offre.
3. Connectez-vous en candidat (kofi@demo.tg) : score de compatibilite, favoris, lettre generee.
(Si vous aviez deja des donnees : lancez 3_REINITIALISER_DONNEES.bat pour avoir les 11 offres de demonstration.)

TESTER L'ABONNEMENT (paiement de demonstration, aucun argent reel)
1. Connectez-vous avec valide@demo.tg (candidat) ou pro@demo.tg (entreprise), mot de passe Demo1234!
2. Menu "Mon espace" > Abonnement : choisissez une duree et une offre, puis Payer.
3. Un recu s'affiche, le compte devient Actif et un espace dedie est cree.
4. "Simuler un echec" montre le cas d'un paiement refuse.

TESTER LES SESSIONS
- Connectez-vous avec le meme compte dans deux navigateurs : le premier est deconnecte avec un message.
- Sans activite, un avertissement apparait puis la deconnexion automatique (30 min par defaut).

INSTALLER LE SITE COMME APPLICATION : voir DEPLOIEMENT.md (disponible sur le site publie en HTTPS).

TESTER LES ALERTES DE SECURITE
1. Connectez-vous en candidat (kofi@demo.tg) dans Chrome, puis dans un autre navigateur (Edge/Firefox) : alerte "nouvelle connexion" + "session fermee" (menu > Securite).
2. Tapez 5 fois un mauvais mot de passe : alerte a la 3e erreur, verrouillage a la 5e. En administrateur : carte Securite > Debloquer.
3. Menu Securite > "Ou recevoir mes alertes" > "Envoyer une alerte de test" (mode demo : visible dans l'application et la fenetre noire API).
